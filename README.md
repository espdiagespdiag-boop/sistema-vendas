# Sistema de Vendas e Facturamento

Este repositório contém o sistema integrado de vendas e facturamento.

## Subprojetos

- **facturacao-web**: Sistema de faturação web
  - Repositório: https://github.com/Sebastiao-Domingos/facturacao-web
  - Stack: TypeScript, Next.js

## Como clonar com submódulos

```bash
git clone --recurse-submodules https://github.com/espdiagespdiag-boop/sistema-vendas.git
```

Se já tiver clonado sem submódulos:
```bash
git submodule update --init --recursive
```

## Desenvolvimento

Cada subprojeto possui suas próprias instruções de configuração. Veja o README específico de cada um.
